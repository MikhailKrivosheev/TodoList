# ZalogHub · Todo List

Тестовое задание ZalogHub (Junior Frontend Developer): список задач на React и TypeScript.

**Демо:** https://mikhailkrivosheev.github.io/TodoList/

**Затраченное время:** 1 час

## Возможности

- **Задачи:** добавление кнопкой или по Enter, переключение «выполнена / активна», удаление,
  редактирование. Пустую задачу или задачу из одних пробелов добавить нельзя: поле подсвечивается и
  показывает подсказку.
- **Описание:** можно добавить при создании или в редакторе, в карточке разворачивается по клику.
- **Срок:** выбирается в календаре. Задачи со сроком сегодня или завтра и просроченные выделяются
  красным. В шапке показана ближайшая по сроку задача: по клику список прокручивается к ней.
- **Фильтры:** все, активные, выполненные, со счётчиками. Фильтр хранится кверями
  (`?filter=active`).
- **Очистка выполненных** одной кнопкой и счётчик оставшихся задач.
- **Сохранение** в `localStorage`. Изменения подтягиваются в других открытых вкладках. Повреждённые
  данные не ломают приложение, а задачи из старых версий переносятся.
- **Интерфейс:** светлая и тёмная тема (по умолчанию — как в системе, переключается кнопкой в
  шапке), адаптивная вёрстка, анимации. Всем можно пользоваться с клавиатуры и скринридера. При
  системной настройке «уменьшить движение» анимации отключаются.

## Структура

Архитектура — [FSD](https://feature-sliced.design/). Слой импортирует только из слоёв ниже себя, в
слайс заходят через его `index.ts`. Оба правила проверяет ESLint.

```text
src/
├── app/                        точка входа, провайдеры, глобальные стили, интеграционные тесты
├── pages/
│   └── todo-page/              страница: шапка со счётчиком и ближайшим сроком, раскладка
├── widgets/
│   ├── todo-list/              анимированный список, пустые состояния, прокрутка к задаче
│   ├── todo-toolbar/           фильтры и «Очистить выполненные»
│   └── app-footer/             подвал
├── features/
│   ├── add-todo/               форма добавления с описанием и сроком
│   ├── edit-todo/              редактор названия, описания и срока
│   ├── toggle-todo/            отметка «выполнена»
│   ├── delete-todo/            удаление
│   ├── filter-todos/           фильтр в адресе страницы (?filter=)
│   ├── clear-completed/        очистка выполненных
│   └── switch-theme/           переключение светлой и тёмной темы
├── entities/
│   └── todo/
│       ├── model/              тип задачи, стор Zustand, валидация, фильтры, сроки
│       ├── lib/                разбор и миграция данных из localStorage
│       └── ui/                 карточка задачи, метка срока
└── shared/
    ├── ui/                     кнопки, чекбокс, календарь, иконки
    ├── lib/                    даты, склонения, клавиатура, хук «сегодня»
    ├── styles/                 токены, миксины, базовые стили, шрифты
    ├── assets/fonts/           Inter: кириллица и латиница
    └── config/tests/           настройка окружения тестов
```

Внутри слайса код разложен по сегментам: `model` — состояние и логика, `ui` — компоненты, `lib` —
вспомогательные функции. Компонент лежит в своей папке: `component.tsx`, `component.module.scss`,
`types.ts`, `index.ts`. Тесты лежат рядом с кодом, который проверяют (`*.test.ts`).

## Запуск

Нужны [nvm](https://github.com/nvm-sh/nvm) и pnpm. Версия Node.js указана в `.nvmrc`, версия pnpm —
в поле `packageManager` в `package.json`.

```bash
nvm install        # если нужной версии Node.js ещё нет
nvm use
corepack enable    # если pnpm не установлен
pnpm install
pnpm dev           # http://localhost:5173
```

## Сборка

```bash
pnpm build         # проверка типов и сборка в dist/
pnpm preview       # просмотр собранной версии
```

## Тесты и проверки

```bash
pnpm test            # тесты
pnpm test:watch      # тесты в режиме наблюдения
pnpm test:coverage   # тесты с отчётом о покрытии
pnpm typecheck       # проверка типов
pnpm lint            # ESLint и Stylelint
pnpm format          # Prettier
pnpm check           # всё сразу: типы, линтеры, форматирование, тесты
```
